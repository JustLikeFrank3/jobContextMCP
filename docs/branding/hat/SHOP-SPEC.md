# jobContext hat — embroidery spec

One custom cap (New Era 59FIFTY/9FIFTY class, dark graphite), three
embroidery locations. Vector sources (SVG) and 2000 px transparent PNGs
are included for every design — digitize from the SVGs where possible.

## Colors (2 threads total)

| Element | Hex | Notes |
| --- | --- | --- |
| Teal (ring, `C`, side/back text) | `#00B5C8` | Bright turquoise/teal — match thread to hex |
| White (`j`, binary digits) | `#FFFFFF` | Standard white |

Use the same teal thread on all three locations.

## Location 1 — Front: circular badge, 3D puff

**Art:** `jobcontextmcp-hat-badge-puff-knockout` (SVG + PNG)

- Size: ~2.25 in (57 mm) diameter, centered on front panels.
- Background: open — no fill stitch; hat fabric shows through the badge.
- **3D puff:** the `jC` letters and the teal outer ring only.
  Stroke widths at 57 mm: letters ~5 mm, ring ~4.3 mm.
- **Flat stitch:** the `00100100` text (white). Digit height at 57 mm is
  ~5 mm — if that is below your minimum for clean small text, scale the
  whole badge up before shrinking the text relative to the badge.

## Location 2 — Right side: slogan, flat

Text: `Context is key.` — teal `#00B5C8`, flat stitch.
Font: JetBrains Mono Bold (free, Google Fonts). ~0.4–0.5 in cap height,
placed on the right side panel.

## Location 3 — Back: wordmark, flat

Text: `jobContext.ai` — flat stitch, centered above the closure.
Font: Space Grotesk Bold (free, Google Fonts).
Two-color: `job` and `.ai` in white, `Context` in teal `#00B5C8`.
(Single-color all-teal is an acceptable simplification.)

## Alternate art in this folder

- `jobcontextmcp-hat-badge-puff` — same badge with a solid dark disc
  (`#0A0F1C`) if an open center isn't wanted; adds a third thread color.
- `jobcontextmcp-hat-dark-hats` / `-light-hats` — plain `jC` mark without
  ring/binary; simplest possible puff design.
- `jobcontextmcp-hat-lockup-*` — wide badge + wordmark lockups (~2.9:1)
  if a single full-width front design is preferred over badge + text.
- `jobcontextmcp-hat-badge` / `-badge-knockout` — original thin-ring
  badges, flat embroidery only (ring too thin for puff).
